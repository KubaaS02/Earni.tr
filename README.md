# Earni.tr
Web app for freelancers to track projects, time, and income with analytics, earnings forecasts, and currency conversion.
## Features:

- Project and task tracking

- Work time tracking

- Rate and income tracking

- Reports (daily and monthly)

- Earnings forecasting based on historical data

- Currency conversion (PLN → EUR)

- CSV export

## Tech Stack:

- Frontend: Django, React/TypeScript

- Backend: FastAPI (Python) → Frogger server

- Database: SQLite

## Automations:

- Automatic time calculation

- Automatic daily/monthly totals

- Fetching exchange rates from an API
